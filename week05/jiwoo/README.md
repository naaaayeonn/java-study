# 5주차 — 자바 API 패키지, 예외처리, 모듈

## Java API

Java API(Application Programming Interface)는 Java에서 기본적으로 제공하는 클래스와 인터페이스의 모음이다. 문자열 처리, 수학 계산, 날짜 및 시간 처리 등 다양한 기능을 제공한다.

### 주요 Java API

- `String`: 문자열을 저장하고 처리하는 클래스이다.
- `Math`: 수학 연산에 필요한 메서드를 제공한다.
- `Random`: 난수를 생성하는 클래스이다.
- `ArrayList`: 크기가 변하는 리스트를 관리하는 클래스이다.
- `Scanner`: 키보드 입력 등을 처리하는 클래스이다.

## 패키지(Package)

패키지는 관련된 클래스와 인터페이스를 묶어 관리하는 단위이다.

- `package`: 클래스가 속한 패키지를 선언한다.
- `import`: 다른 패키지에 있는 클래스를 사용할 수 있도록 한다.
- 클래스 이름의 충돌을 방지하고 코드를 체계적으로 관리할 수 있다.

### 주요 패키지

- `java.lang`: String, Math 등 기본적인 클래스를 제공한다.
- `java.util`: Scanner, Random, ArrayList 등 다양한 유틸리티 클래스를 제공한다.
- `java.io`: 파일 및 데이터 입출력에 필요한 클래스를 제공한다.
- `java.time`: 날짜와 시간을 처리하는 클래스를 제공한다.

## 예외처리(Exception Handling)

예외처리는 프로그램 실행 중 발생할 수 있는 오류 상황을 처리하여 프로그램이 비정상적으로 종료되는 것을 방지하는 방법이다.

### 주요 키워드

- `try`: 예외가 발생할 가능성이 있는 코드를 작성한다.
- `catch`: 발생한 예외를 처리한다.
- `finally`: 예외 발생 여부와 관계없이 실행할 코드를 작성한다.
- `throw`: 예외를 직접 발생시킨다.
- `throws`: 메서드에서 발생할 수 있는 예외를 호출한 곳으로 전달하도록 선언한다.

### 주요 예외

- `ArithmeticException`: 0으로 정수를 나누는 등 잘못된 산술 연산 시 발생한다.
- `NumberFormatException`: 문자열을 숫자로 변환할 수 없을 때 발생한다.
- `ArrayIndexOutOfBoundsException`: 배열의 인덱스 범위를 벗어났을 때 발생한다.
- `NullPointerException`: null인 참조 변수로 객체의 멤버에 접근할 때 발생한다.

## 모듈(Module)

모듈은 관련된 패키지와 리소스를 하나로 묶어 관리하는 단위이다. Java 9부터 도입되었다.

- `module-info.java` 파일을 이용하여 모듈을 정의한다.
- `requires`: 다른 모듈에 대한 의존성을 선언한다.
- `exports`: 다른 모듈에서 사용할 수 있도록 패키지를 공개한다.
- 모듈을 사용하면 프로그램의 의존성과 접근 범위를 명확하게 관리할 수 있다.

## 학습 정리

Java API를 활용하면 필요한 기능을 직접 구현하지 않고 제공되는 클래스와 메서드를 사용할 수 있다. 패키지는 관련된 클래스를 체계적으로 관리하는 역할을 하며, 예외처리는 프로그램 실행 중 발생하는 오류 상황을 처리하는 데 사용된다. 또한 모듈을 통해 패키지 간 의존성과 접근 범위를 관리할 수 있다는 점을 학습하였다.
