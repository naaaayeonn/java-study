# 4주차 — 추상 클래스, 인터페이스, 중첩 클래스

## 추상 클래스(Abstract Class)

추상 클래스는 객체를 직접 생성할 수 없으며, 자식 클래스에서 공통으로 사용할 필드와 메서드를 정의하는 클래스이다.

- `abstract` 키워드를 사용하여 선언한다.
- 추상 메서드는 구현부 없이 선언하며, 자식 클래스에서 구현하도록 한다.
- 일반 메서드와 필드, 생성자도 포함할 수 있다.
- 추상 클래스를 상속받은 일반 클래스는 상속받은 추상 메서드를 모두 구현해야 한다.

### 추상 클래스의 특징

- 여러 자식 클래스의 공통 기능을 정의할 수 있다.
- 자식 클래스마다 서로 다른 동작을 구현할 수 있다.
- 클래스 상속에는 `extends` 키워드를 사용한다.

## 인터페이스(Interface)

인터페이스는 클래스가 구현해야 하는 동작을 정의하는 일종의 규약이다.

- `interface` 키워드를 사용하여 선언한다.
- 클래스에서는 `implements` 키워드를 사용하여 구현한다.
- 인터페이스의 추상 메서드는 기본적으로 `public abstract`이다.
- 인터페이스의 필드는 기본적으로 `public static final` 상수이다.
- 하나의 클래스가 여러 인터페이스를 구현할 수 있다.
- Java 8부터 `default`, `static` 메서드도 정의할 수 있다.

### 추상 클래스와 인터페이스의 차이

| 구분 | 추상 클래스 | 인터페이스 |
| --- | --- | --- |
| 선언 | `abstract class` | `interface` |
| 사용 | `extends` | `implements` |
| 다중 적용 | 클래스 단일 상속 | 여러 인터페이스 구현 가능 |
| 주요 목적 | 공통 속성과 기능 정의 | 동작 규약 정의 |

## 중첩 클래스(Nested Class)

중첩 클래스는 클래스 내부에 선언된 클래스이다. 관련된 클래스를 하나로 묶어 관리할 때 사용한다.

- 인스턴스 멤버 클래스: 바깥 클래스의 객체와 연결되어 사용된다.
- 정적 멤버 클래스: `static`으로 선언하며 바깥 클래스 객체 없이 생성할 수 있다.
- 지역 클래스: 메서드나 생성자 등의 블록 내부에서 선언한다.
- 익명 클래스: 이름 없이 선언과 동시에 객체를 생성하는 클래스이다.

### 중첩 클래스의 장점

- 관련된 코드를 하나의 클래스 내부에 정리할 수 있다.
- 외부에 불필요한 클래스 노출을 줄일 수 있다.
- 코드의 구조와 유지보수성을 개선할 수 있다.

## 학습 정리

추상 클래스는 공통 기능을 상속하는 데 활용하며, 인터페이스는 클래스가 구현해야 하는 동작을 정의한다. 중첩 클래스는 관련된 클래스를 내부에 선언하여 코드를 구조적으로 관리할 수 있도록 한다.
